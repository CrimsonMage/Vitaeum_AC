The project

Parity without carrying the past forward.

Vitaeum preserves observable retail behavior while replacing legacy runtime assumptions with focused Rust systems. Storage, resources, world state, networking, UI, and rendering remain deliberate, separate concerns.

01

Parity first

Retail behavior is traced and preserved rather than approximated from memory.

02

Modern foundation

Rust ownership and focused APIs replace legacy lifetime and interface patterns.

03

Built to travel

Windows, Linux, and macOS are treated as first-class release targets.
