About the project

Why I'm rebuilding it.

The original retail client is a work of art, but time has caught up with it. Memory leaks and aging technology, such as DirectX 9, increasingly limit the experience. I want a modern client that lets us enjoy the game we love without those technical constraints.

Follow retail behavior

I compare against what the client actually does, not memory or guesswork.

Modernize the client

Rust and wgpu modernize the client. Rust adds memory safety, helping me correct memory leaks as they appear.

Support all three platforms

Windows, Linux, and macOS are part of the plan from the beginning.
